# 🌎 ClimateAI Bot

Bot de conscientização ambiental para Discord, desenvolvido em Python como parte de um Hackathon sobre mudanças climáticas.

## ✨ Funcionalidades

- `/clima [cidade]` — Consulta condições meteorológicas.
- `/dica` — Apresenta dicas de sustentabilidade.
- `/sobre` — Apresenta informações sobre o projeto.

## 🛠️ Tecnologias

- Python
- Discord.py
- Open-Meteo API
- Aiohttp

## 🚀 Instalação

1. Clone o repositório.
2. Crie um ambiente virtual.
3. Instale as dependências com `pip install -r requirements.txt`.
4. Configure o arquivo `.env` com seu token do Discord.
5. Execute `python bot.py`.

## 🌱 Objetivo

Promover a conscientização ambiental e facilitar o acesso a informações meteorológicas.
